# Аренда строительного оборудования

## 1. Название и описание проекта
Проект "Аренда строительного оборудования" (trade-project-db) предназначен для автоматизации учёта выдачи и возврата строительной техники. 

Что делает проект:
- Ведёт каталог оборудования (бетономешалки, перфораторы, строительные леса, генераторы)
- Регистрирует клиентов и оформляет договоры аренды
- Рассчитывает стоимость аренды по дням
- Отслеживает доступность оборудования

Какие проблемы решает:
- Убирает ручной учёт в журналах
- Снижает ошибки человеческого фактора
- Ускоряет оформление аренды

Почему ценен:
- Подходит для небольших строительных фирм и пунктов проката
- Простая установка и использование
